# Sample Output

Deliberately empty.

DO-07 is at v0.1 and has not yet produced a reviewed locale variant. Putting
machine-translated DE, FR and NL versions of the warranty policy here would look
like sample output and would not be: nobody who reads those languages has checked
them, and the family is tagged `warranty, legal`, which means the skill itself
treats its output as a review draft rather than a finished variant.

Once a real run has been reviewed, the approved variants belong here alongside the
sync-index file the run produced.
